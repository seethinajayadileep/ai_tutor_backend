🎤 AI Voice Tutor — Backend

This backend receives audio from the frontend, converts speech to text using Deepgram, and gets the answer from Claude AI.
It returns the transcript and the tutor’s explanation.
Built using Node.js + Express and deployed on Render.
Main API endpoint:
👉 POST /uploadFile

Backend URL:
👉 https://ai-tutor-backend-hfu2.onrender.com
